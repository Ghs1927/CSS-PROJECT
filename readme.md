# Pato Place - Restaurant Website

A multi-page website built for a restaurant called Pato Place, created using HTML and CSS.

## Pages
- `index.html` - Homepage with intro banner, menu highlights, and video section.
- `menu.html` - Full food and drinks menu layout with prices.
- `reservation.html` - Table booking form page.
- `gallery.html` - Photo grid showcasing dishes and restaurant atmosphere.
- `about.html` - Restaurant background story and chef profiles.
- `blog.html` - Articles, recipes, and updates.
- `contact.html` - Contact information, operating hours, map, and message form.

## Tech Used
- **HTML5**
- **CSS3** (Flexbox, CSS Grid, and custom stylesheets for each page)
